# 영상 AI 바꾸기 (사용자 워크플로)

H3 대신 다른 영상 모델을 쓰고 싶을 때, ComfyUI 워크플로를 직접 만들어 넣으면 38Sprite가 그 워크플로로 영상을 만듭니다. 코드는 고치지 않아도 됩니다.

## 1. 설정 바꾸기

`config.json`:

```json
{
  "video_backend": "custom",
  "workflow_dir": "workflows"
}
```

## 2. 워크플로 파일 만들기

| 파일 | 필요 여부 | 쓰이는 곳 |
|---|---|---|
| `workflows/i2v.json` | 필수 | 글 모드 (첫 프레임 → 영상) |
| `workflows/r2v.json` | 선택 | 레퍼런스 영상 모드, 3D 마네킹 모드 (캐릭터 그림 + 동작 영상 → 영상) |

만드는 방법:

1. ComfyUI에서 원하는 모델로 이미지→영상 워크플로를 만들고 잘 되는지 확인합니다.
2. 메뉴에서 **API 형식으로 내보내기**(Export (API))로 JSON을 저장합니다.
3. JSON 안의 값들을 아래 **자리표시자**로 바꿉니다.
4. `workflows/i2v.json`(또는 `r2v.json`)으로 저장합니다.

H3로 만든 예시가 `workflows/example_h3_i2v.json`, `workflows/example_h3_r2v.json`에 있습니다. 자리표시자를 어디에 넣는지 보는 데 참고하세요.

## 3. 자리표시자

JSON 값에 `"{{이름}}"`을 적으면 앱이 실행할 때 실제 값으로 바꿉니다. 값 전체가 자리표시자이면 숫자는 숫자로 들어갑니다.

| 자리표시자 | i2v | r2v | 들어가는 값 |
|---|---|---|---|
| `{{FIRST_IMAGE}}` | ○ | | 첫 프레임 그림 (ComfyUI input 폴더에 올라간 파일 이름) |
| `{{LAST_IMAGE}}` | ○ | | 마지막 프레임 그림 (반복 동작은 첫 프레임과 같음) |
| `{{REF_IMAGE}}` | | ○ | 캐릭터 그림 (그 방향) |
| `{{REF_VIDEO}}` | | ○ | 따라 할 동작 영상 (mp4) |
| `{{PROMPT}}` | ○ | ○ | 동작 설명 프롬프트 (영어) |
| `{{WIDTH}}`, `{{HEIGHT}}` | ○ | ○ | 영상 크기 (기본 640×640) |
| `{{LENGTH}}` | ○ | ○ | 프레임 수 (5초 = 124) |
| `{{SEED}}` | ○ | ○ | 시드 |
| `{{STEPS}}` | ○ | ○ | 스텝 수 (앱이 정한 값. 모델에 맞게 무시해도 됨) |
| `{{PREFIX}}` | ○ | ○ | 결과 저장 이름. **SaveImage의 filename_prefix에 꼭 넣으세요** |

## 4. 지켜야 할 것

- **결과는 PNG 프레임으로 저장하세요.** `SaveImage` 노드 하나에 `filename_prefix: "{{PREFIX}}"`를 넣으면, 앱이 그 프레임들을 받아 갑니다.
- **24fps 기준으로 처리합니다.** 다른 fps로 나오면 재생 속도가 달라질 수 있습니다.
- **배경을 유지해야 합니다.** 첫 프레임은 마젠타(#FF00FF) 배경입니다(마네킹 모드는 회색). 모델이 배경을 바꾸거나 무늬를 그리면 오리기가 망가집니다. 중간에 초록 배경으로 바뀌는 정도는 앱이 자동으로 처리합니다.
- **반복 동작은 첫·마지막 프레임을 같게** 넣어야 루프가 자연스럽습니다. 모델이 마지막 프레임 지정을 지원하지 않으면 반복 구간 찾기에만 의존하게 됩니다.
- 프롬프트에는 H3 형식의 `<Picture 1>`, `<Video 1>` 같은 표현이 들어 있습니다. 다른 모델에서는 그대로 두거나, 워크플로에서 `{{PROMPT}}` 앞뒤에 그 모델에 맞는 문장을 붙여 쓰세요.
- 사용자 워크플로에서는 H3 전용 기능인 "중간 자세 고정"을 쓰지 않습니다.

## 확인

설정을 바꾸고 앱을 새로고침하면 상태 표시에 "영상 AI(사용자 워크플로): 사용 가능"이 나옵니다. `i2v.json`이 없으면 그 경로를 알려 줍니다.
